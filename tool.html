使用说明

需要安装

  • Node.js 18 或更高版本（自带 npm） 官网下载地址： https://nodejs.org/en/download
    快捷入口： Windows Mac
  • Chrome 或 Edge
  1. 1. 下载压缩文件

    点击下载按钮，把压缩包下载到电脑上。

  2. 2. 解压并保留文件夹

    压缩包解压后，将整个 vfx-browser 文件夹拖拽到特效文件的根目录。

  3. 3. 启动对应脚本

    打开 vfx-browser 文件夹，Windows 双击 start.bat，Mac 双击 start.command。脚本会先 build，再启动本地服务并打开浏览器；如果 Node/npm 没装好，会直接提示原因。
